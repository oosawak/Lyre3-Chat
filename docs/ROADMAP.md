# Lyre3 Chat Roadmap

## Phase 1: Prototype

- 1画面チャット
- Prompt API 接続
- 非対応端末でのモック
- 人格プリセット
- 編集可能なプロンプト欄

## Phase 2: Story Mode

- ゲームマスター型の初回導入
- 固定登場人物 3 人の管理
- 物語状態の保存
- シーン切り替え
- 会話要約の導入

## Phase 3: Prompt Orchestration

- 裏側 LLM によるプロンプト生成
- JSON ベースのシーン表現
- 登場人物カード
- 世界観テンプレート
- テンプレート切り替え

## Phase 4: Productization

- プリセット世界観の追加
- プロンプトのエクスポート / インポート
- 物語の共有機能
- 進行ログの保存
- 操作説明の整備

## Phase 5: Service Expansion

- 複数ジャンル対応
- 有料テンプレート
- 公式シナリオ配布
- ユーザー作成テンプレートの共有
- LLM の差し替え対応

## 直近の優先事項

1. ゲームマスター型ストーリーの安定化
2. 固定登場人物 3 人の導入
3. シーン要約の保存
4. 裏側 LLM のプロンプト生成機構
5. ユーザー向けのテンプレート編集 UX
