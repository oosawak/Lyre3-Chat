# Lyre3 Chat Project Brief

## 概要

Lyre3 Chat は、Chrome の組み込み AI Prompt API を使って Gemini Nano と会話しながら物語を進める、端末内重視のインタラクティブ物語アプリです。

このプロジェクトの主眼は、単なる雑談チャットではなく、**ゲームマスターが物語を進行し、固定の登場人物 3 人が場面を動かす体験**をつくることにあります。

## 目標

- 端末内 AI を使って、軽くて速い物語体験を提供する
- ユーザーが会話の主導権を持ちながら物語に参加できるようにする
- カスタム指示を保存し、世界観や人格を簡単に切り替えられるようにする
- 裏側の LLM で物語設計を行い、Gemini Nano には会話の実行を担当させる
- 固定キャラを `ミナ / レイ / シオ` に絞って、見通しのよい会話を保つ

## 価値

- プライバシー性が高い
- 端末内で完結しやすい
- 長い設定文を毎回送らなくて済む
- 物語テンプレートを商品化しやすい
- 今後、複数ジャンルへ展開しやすい

## 想定ユーザー

- 物語を会話で進めたい人
- キャラクターと会話しながら遊びたい人
- 端末内で軽く動く AI 体験を求める人
- 自分用の世界観や人格を作って遊びたい人

## コア体験

1. ユーザーが人格や物語テンプレートを選ぶ
2. アプリが初回シーンを立ち上げる
3. 固定の登場人物が会話を返しながら物語を進める
4. ユーザーの返答で場面が少しずつ変化する
5. 必要に応じて裏側の LLM が次のシーン用プロンプトを更新する

## 収録済みの試作要素

- Prompt API の利用可否確認
- モデル準備状態の表示
- ダウンロード進捗の表示
- 人格プリセット切り替え
- カスタム指示の保存
- AI に渡すプロンプトの編集
- 会話履歴の保存
- 物語開始時の導入処理

## 今後の正式版方針

- ゲームマスター型の物語開始を標準にする
- 固定登場人物を 3 人に固定する
- 外部 LLM は物語設計と要約に限定する
- Gemini Nano は会話生成に集中させる
- プロンプトと状態を保存して、継続的に遊べるようにする

## 成功条件

- 初回起動で物語が自然に始まる
- ユーザーが「何をすればいいか」を毎回理解しやすい
- 人格や世界観の切り替えが簡単
- 物語の一貫性が保たれる
- 実装が軽く、ローカル環境で安定して動く
